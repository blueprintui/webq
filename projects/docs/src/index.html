webq

Tools for querying and validating Web Components against Custom Elements Manifest (CEM) files.

Install

curl -fsSL https://raw.githubusercontent.com/blueprintui/webq/main/projects/cli/install.sh | bash

Or via npm:

npm install -g @webq/cli

Packages

  • @webq/cli — CLI and MCP server for querying CEM files and validating HTML.
  • @webq/eslint — ESLint plugin (18 rules) backed by the CLI's validation engine.
  • schemas — JSON schemas for custom-elements, custom-attributes, custom-patterns, custom-styles, DTCG tokens, and VSCode custom data.

Usage

webq element.list --path ./node_modules
webq element bp-button --path ./node_modules
webq validate-html '<bp-button variant="primary">Click</bp-button>' --path ./node_modules
webq mcp --path ./node_modules

Develop

bun install
bun run ci
bun --filter @webq/cli run start
